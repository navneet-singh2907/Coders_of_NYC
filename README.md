# Coders of NYC: The OpenAI Follower Challenge

A 24-hour engineering sprint to analyze the OpenAI follower base using unstructured, manually collected data. This project demonstrates the ability to build resilient data pipelines under extreme time constraints and "dirty" data conditions.

## Engineering Achievements
* **Unstructured Data Parsing:** Built a custom "chunk-based" parser to group multi-line text into structured Python dictionaries.
* **Numerical Scaling Engine:** Implemented logic to normalize human-readable metrics (e.g., "681K", "1.2M") into integers for mathematical comparison.
* **Defensive Programming:** Engineered "IndexError" guards and "NoneType" safety nets to handle inconsistent manual entries.
* **Set Theory Optimization:** Utilized Python Sets for $O(1)$ category discovery and diversity mapping.
